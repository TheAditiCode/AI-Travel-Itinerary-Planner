# VoyageAI - AI Travel Planner

## Overview
VoyageAI is an AI-powered travel planner that generates personalized travel itineraries based on user preferences.

## Features
- AI-powered itinerary generation
- Budget planning
- Trip duration selection
- Destination recommendations
- Responsive dark UI
- Rating system

## Tech Stack
- HTML
- CSS
- JavaScript
- Gemini API
- Git & GitHub
